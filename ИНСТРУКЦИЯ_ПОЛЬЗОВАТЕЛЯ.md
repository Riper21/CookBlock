# Инструкция пользователя «Пищеблок»

Персональный Telegram-бот: диетолог-нутрициолог и семейный шеф-повар. Составляет
меню на день и неделю под ваши цели, считает КБЖУ любых блюд (текстом, по фото
и голосом), ведет дневник питания и список покупок, помогает при тяге к сладкому.

Инструкция рассчитана на человека без опыта программирования. Если что-то пошло
не так — раздел «Диагностика» в конце покрывает 95% случаев.

---

## 1. Установка на Windows (один раз, ~10 минут)

### Шаг 1. Установите Python

1. Откройте https://www.python.org/downloads/ и скачайте **Python 3.12** (или 3.11/3.10).
2. Запустите установщик.
3. **ВАЖНО:** на первом экране поставьте галочку **«Add Python to PATH»**
   (внизу окна), затем «Install Now».

### Шаг 2. Скачайте папку бота

Скачайте репозиторий кнопкой «Download ZIP» (или `git clone`) и распакуйте,
например, в `C:\Пищеблок`. Папка должна содержать файлы `main.py`,
`requirements.txt`, `ЗАПУСК_БОТА.cmd`.

### Шаг 3. Первый запуск

Дважды кликните **`ЗАПУСК_БОТА.cmd`**. При первом запуске скрипт:

1. создаст файл `.env` из шаблона и откроет его в Блокноте — пока просто
   закройте Блокнот (настроим на следующем шаге), окно скрипта поставится на
   паузу — нажмите любую клавишу;
2. создаст изолированное окружение `.venv` и скачает зависимости
   (несколько минут, нужен интернет);
3. проверит настройки и скажет, чего не хватает — это нормально: ключей еще нет.

### Шаг 4. Впишите два ключа в `.env`

Откройте файл `.env` в папке бота (Блокнотом) и заполните (см. раздел 2),
запустите `ЗАПУСК_БОТА.cmd` еще раз. Готово: в окне появится строка
«Бот успешно запущен и готов к работе», а в Telegram по команде `/start` бот
поздоровается и начнет анкету.

## 2. Настройка — два ключа

### 2.1. Токен Telegram-бота (TELEGRAM_BOT_TOKEN)

У каждого человека — свой бот, свой токен. Создание занимает 2 минуты:

1. В Telegram найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Придумайте имя (например, «Мой нутрициолог») и username
   (обязательно на латинице с окончанием `bot`, например `my_nutrition_bot`).
4. BotFather пришлет **токен** вида `1234567890:AAH4g9...` — скопируйте его
   целиком и вставьте в `.env` в строку `TELEGRAM_BOT_TOKEN=`.

### 2.2. Ключ нейросети (DEEPSEEK_API_KEY)

Мозг бота — нейросеть через API. Дешевле всего — DeepSeek:

1. Зарегистрируйтесь на https://platform.deepseek.com/.
2. Раздел **API Keys** → «Create new API key» → скопируйте ключ
   (начинается с `sk-`).
3. Вставьте в `.env` в строку `DEEPSEEK_API_KEY=`.
4. В разделе Billing пополните баланс минимум на $2 — этого хватает на
   месяцы личного использования.

### 2.3. Хотите разбор фото блюд?

Анализ фотографий тарелок требует **мультимодальной** модели. Обычный ключ
DeepSeek с моделью `deepseek-chat` — только текст (меню, КБЖУ, рецепты, чат —
все работает, фото — нет: бот сам сообщит об этом).

Варианты включить фото:

- любой OpenAI-совместимый провайдер с Vision-моделью: укажите в `.env`
  его адрес в `LLM_BASE_URL`, модель в `LLM_MODEL`, ключ в `DEEPSEEK_API_KEY`;
- либо переключитесь на Google Gemini (`LLM_PROVIDER=gemini`, ключ
  [aistudio.google.com](https://aistudio.google.com/apikey) в `GEMINI_API_KEY`,
  модель с Vision по умолчанию).

### 2.4. Полезные опции `.env` (не обязательно)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `LLM_TIMEOUT` | 120 | Таймаут ответа нейросети, сек. Ошибки таймаута — увеличьте |
| `WHISPER_MODEL` | tiny | Качество распознавания голоса: tiny → base → small (точнее, но медленнее) |
| `PROXY_URL` | пусто | Прокси, если Telegram/API недоступны напрямую |

## 3. Как пользоваться (основное)

После `/start` бот проведет короткую анкету (пол, возраст, вес, цель...) и
рассчитает вашу норму КБЖУ. Дальше — главная клавиатура с кнопками.

| Команда | Что делает |
|---|---|
| `/daymenu` | ☀️ Меню на день с рецептами и граммовками |
| `/menu` | 📅 Меню на неделю + интерактивный список покупок |
| `/family` | 👨‍👩‍👧 Семейный ужин: одно блюдо, разные тарелки для него и неё |
| `/photo` | 📸 Оценить блюдо по фото (нужна Vision-модель, см. 2.3) |
| `/voice` | 🎙️ Надиктовать еду голосом — распознается локально на вашей машине |
| `/fridge` | 🍳 Что приготовить из того, что есть в холодильнике |
| `/kbzhu` | 📊 Рассчитать КБЖУ блюда по описанию текстом |
| `/sos` | 🍫 SOS: тянет на сладкое / случился срыв |
| `/diary` | 📖 Дневник питания за сегодня с прогресс-барами |
| `/favorites` | ⭐ Сохраненные меню и рецепты |
| `/profile` | 👤 Профиль и норма КБЖУ, точечное редактирование |
| `/reset` | 🔄 Сбросить контекст диалога с нутрициологом |

Можно просто писать боту текстом как живому нутрициологу — он поддержит
контекст диалога.

**Данные** (профиль, дневник, избранное) хранятся локально в файле
`nutrition_chef.db` в папке бота. Удалили папку — данных нет.

**Приватность:** голосовые сообщения расшифровываются локально (Whisper на
вашей машине) и наружу не уходят. Текст вопросов и фото (если Vision включен)
уходят в нейросеть, которую вы настроили в `.env`.

## 4. Ежедневный запуск и остановка

- **Запуск:** двойной клик `ЗАПУСК_БОТА.cmd`. Окно должно оставаться открытым,
  пока работает бот. Остановка — закрыть окно или `Ctrl+C`.
- Бот работает, пока запущен на вашем компьютере. Хотите 24/7 — нужен сервер
  или VPN-приставка с всегда включенной машиной.
- Повторный запуск быстрый: окружение и зависимости уже стоят.

## 5. Диагностика

| Симптом | Причина | Решение |
|---|---|---|
| Окно сразу: «Python не найден» | Python не установлен / без PATH | Переустановите Python 3.10–3.12 с галочкой «Add Python to PATH» (раздел 1) |
| «Создан файл .env ... укажите токены» | Ключи не заполнены | Впишите `TELEGRAM_BOT_TOKEN` и `DEEPSEEK_API_KEY` (раздел 2) |
| «ТЕЛЕГРАМ_ТОКЕН отклонен / содержит заглушку» | Токен скопирован не полностью/с пробелами | Скопируйте заново из @BotFather, без кавычек и пробелов |
| «Не задан ключ нейросети» | Пустой `DEEPSEEK_API_KEY` | Раздел 2.2 |
| `pip install` падает, ошибки сети | Нет интернета / блокировки | Проверьте интернет; для прокси раскомментируйте `PROXY_URL` в `.env` |
| Бот запустился, но молчит | Нет интернета до Telegram / невалидный токен | Проверьте сеть/прокси; токен проверьте в @BotFather (`/mybots`) |
| «Модель не умеет анализировать изображения» | Vision не настроен | Раздел 2.3 или используйте текст/голос |
| Первое голосовое долго думает | Скачивается модель Whisper (~75 МБ) | Подождите; далее будет быстро. Модель кешируется |
| Ошибки таймаута нейросети | Медленный провайдер | Увеличьте `LLM_TIMEOUT` в `.env` (например, 240) |
| «Insufficient Balance» | Баланс DeepSeek исчерпан | Пополните на platform.deepseek.com |

Проверить настройки без запуска бота:

```powershell
.venv\Scripts\python.exe main.py --check
```

## 6. Обновление до новой версии

1. Скачайте новую версию репозитория (папкой поверх старой или заново).
2. Файл `.env` и `nutrition_chef.db` переносятся без изменений — ваши
   настройки и дневник остаются.
3. Если менялись зависимости — удалите файл `.venv\.deps_ok` (или всю папку
   `.venv`) и запустите `ЗАПУСК_БОТА.cmd`: зависимости переустановятся.
