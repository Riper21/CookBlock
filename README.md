# 🥑 Пищеблок — ваш семейный диетолог в Telegram

Telegram-бот, который считает калории, составляет меню под вашу цель и привычки,
разбирает фото тарелок и голосовые заметки. Работает на обычном домашнем
компьютере. Голос распознаётся локально — аудио не покидает вашу машину.

> 🧑‍💻 Вы разработчик или опытный пользователь? Вам сюда: **[README_ADVANCED.md](README_ADVANCED.md)**

---

## Что умеет

- 👤 **Профиль и КБЖУ** — расчёт нормы калорий по формуле Миффлина — Сан Жеора под ваш пол, вес и цель
- ☀️ **Меню на день** — с точными граммовками для кухонных весов, кнопка «Заменить блюдо» в 1 клик
- 📅 **Меню на неделю** — с интерактивным списком покупок и пересылкой списка супругу(е)
- 👨‍👩‍👧 **Семейный ужин** — одно блюдо, но разные порции для неё и для него
- 📖 **Дневник питания** — прогресс-бары съеденного за день и умный совет на остаток нормы
- 📸 **Фото тарелки** — бот определит блюдо и посчитает КБЖУ *(нужна Vision-модель, см. ниже)*
- 🎙️ **Голосовой ввод** — надиктуйте «съел овсянку и два яйца» — бот запишет
- 🍫 **SOS: тяга к сладкому** — 3 экспресс-десерта за 2 минуты и план, если уже съели
- 🍳 **Рецепты из холодильника** — что приготовить из остатков

## Что понадобится

| Что | Детали |
|---|---|
| Компьютер | Windows 10/11, Linux или macOS |
| Python | 3.10 – 3.12, с [python.org](https://www.python.org/downloads/) (при установке отметьте «Add Python to PATH») |
| Место на диске | ~1.5 ГБ |
| Два ключа | 5 минут на получение — см. таблицу ниже |

## Запуск на Windows — 3 шага

1. Установите Python 3.10–3.12 с [python.org](https://www.python.org/downloads/) — обязательно с галочкой **«Add Python to PATH»**.
2. Дважды кликните **`ЗАПУСК_БОТА.cmd`**. При первом запуске он сам создаст настройки, окружение и поставит всё нужное.
3. Откроется файл `.env` — впишите туда **два ключа**:

| Ключ | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → токен вида `1234567890:AA...` |
| `DEEPSEEK_API_KEY` | [platform.deepseek.com](https://platform.deepseek.com/) → API Keys → пополните баланс на пару долларов (хватает надолго) |

Сохраните `.env` и снова запустите `ЗАПУСК_БОТА.cmd` — бот напишет вам в Telegram.

## Запуск на Linux / macOS

```bash
git clone <адрес-репозитория> && cd Пищеблок
bash scripts/unix/run.sh
```
Скрипт сам создаст окружение и при первом запуске попросит заполнить `.env`.

## Про фото тарелок

Разбор фото работает, только если нейросеть умеет видеть картинки (Vision).
Ключ DeepSeek с моделью `deepseek-chat` — только текст. Без Vision бот честно
предупредит при первом фото; меню, дневник, голос и всё остальное будут работать.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Не хватает настроек в .env» | Впишите два ключа из таблицы выше |
| `ModuleNotFoundError` | Запускайте через `ЗАПУСК_БОТА.cmd` — он сам ставит зависимости |
| Бот молчит | Проверьте интернет/прокси и окно консоли с логами |
| Голос долго отвечает первый раз | Модель Whisper (~75 МБ) скачивается один раз |
