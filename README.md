# 🥑 Telegram-бот «Пищеблок»: Персональный Диетолог-Нутрициолог и Семейный Шеф-повар

Умный автономный Telegram-бот на **Aiogram 3** с мозгом из нейросети через OpenAI-совместимый API (по умолчанию **DeepSeek**) и локальным распознаванием речи **faster-whisper** (голос не покидает вашу машину). Создан с заботой о сбалансированном, вкусном и здоровом питании всей семьи.

---

## ✨ Возможности бота

### 1. 👤 Персональный профиль и адаптация под пол
- **Гендерная персонализация:** выбор пола (👩 Женский / 👨 Мужской). Все формулы, граммовки, физиологические акценты (гормональный баланс vs мужская сила и тестостерон) и обращения адаптируются динамически.
- **Научный расчет КБЖУ:** расчет базового метаболизма (BMR) по формуле **Миффлина — Сан Жеора** (+5 для мужчин, -161 для женщин) с учетом активности и индивидуальной цели (похудение, поддержание, тонус, набор массы).
- **Модульное редактирование без потери данных:** быстрая смена цели, веса, пола, числа персон, любимых продуктов, стоп-листа и аллергий без перезаполнения анкеты.

### 2. 👨‍👩‍👧 Семейный ужин — разные тарелки
- Решение извечной проблемы совместного ужина: **готовится одно блюдо в одной сковороде/духовке**, но шеф рассчитывает **раздельные граммовки для кухонных весов**:
  - 👩 **Для Неё:** порция под дефицит/форму, легкость, акцент на клетчатку и нежирный белок.
  - 👨 **Для Него:** сытная мужская порция под силу и тонус с повышенным белком и сложными углеводами.

### 3. ☀️ Меню на день и быстрая замена блюд (🔄)
- Сбалансированный рацион на 1 день (завтрак, обед, ужин, перекус) с точным весом порции в граммах и КБЖУ.
- **Быстрая замена блюд в 1 клик:** кнопки `[ 🔄 Заменить Завтрак ]`, `[ 🔄 Заменить Обед ]`, `[ 🔄 Заменить Ужин ]`, `[ 🔄 Заменить Перекус ]` моментально предлагают 2 альтернативных рецепта с сохранением суточного КБЖУ.

### 4. 📅 Меню на неделю и интерактивный список покупок 🛒
- Меню на 7 дней с учетом частоты готовки (на каждый день или заготовки на 2-3 дня).
- **Интерактивный список покупок прямо в Telegram:**
  - Нажимайте на чек-боксы продуктов (`🔘` ➡️ `🟢 Куплено`), чтобы вычеркивать купленное прямо во время похода в магазин.
  - **Кнопка «📤 Переслать список супругу/супруге»:** в один тап открывает диалог выбора контакта в Telegram с уже предзаполненным аккуратным чек-листом покупок.

### 5. 📖 Дневник питания и трекер динамики веса
- Подсчет съеденных калорий и БЖУ за текущие сутки с визуальными прогресс-барами (`[🟩🟩🟩🟩⬜⬜⬜⬜] 50%`).
- Умный совет нутрициолога на остаток нормы.
- **Быстрая запись в 1 клик:** добавление блюд прямо из расчетов КБЖУ и распознанных фото тарелок.
- **Трекер отвеса:** фиксация истории взвешиваний и подсчет динамики (`📉 Отвес: -1.5 кг`).

### 6. 📸 Анализ фото тарелок (Vision) & Голос (Whisper)
- Отправьте фотографию готового блюда — нейросеть определит ингредиенты, оценит визуальный объем и граммовки и рассчитает КБЖУ. *Требует мультимодальную (Vision) модель в `.env` — см. «Настройка».*
- Отправьте голосовую заметку — бот локально расшифрует аудио через `faster-whisper` (без отправки звука на сторонние сервера) и внесет прием пищи.

### 7. 🍫 SOS: Сладкое / Срыв
- Экстренная психологическая и диетологическая помощь при тяге к сладкому.
- 3 экспресс-десерта за 2-3 минуты из простых ингредиентов для быстрого закрытия тяги без срыва с суточной нормы.
- Четкий план действий, если сладкое уже съедено.

### 8. 🍳 Рецепты из холодильника и ⭐ Избранное
- Подбор блюд из остатков продуктов с пошаговым рецептом и граммовками.
- Сохранение любых меню, рецептов и расчетов в избранное с фильтрацией по категориям.

## 🚀 Установка и запуск

Подробная пошаговая инструкция (для тех, кто не дружит с консолью) — **[ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md](ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md)**.

### Требования
| Что | Сколько |
|---|---|
| ОС | Windows 10/11, Linux, macOS |
| Python | 3.10 – 3.12 (при установке на Windows отметьте «Add Python to PATH») |
| Диск | ~1.5 ГБ (окружение + модель Whisper при первом голосовом сообщении) |
| Ключи | токен Telegram-бота + ключ нейросети (5 минут, см. ниже) |

### Windows — самый простой путь
1. Установите Python 3.10–3.12 с [python.org](https://www.python.org/downloads/) (галочка «Add Python to PATH»!).
2. Дважды кликните **`ЗАПУСК_БОТА.cmd`** — при первом запуске он сам:
   - создаст `.env` из шаблона и откроет его в Блокноте (впишите 2 ключа);
   - создаст изолированное окружение `.venv` и поставит все зависимости;
   - проверит настройки и запустит бота.

### Linux / macOS
```bash
git clone <адрес-репозитория> && cd Пищеблок
bash scripts/unix/run.sh
```
Скрипт сам создаст `.venv`, поставит зависимости и запустит бота (настоятельно заполните `.env` при первом запуске).

### Ручной запуск (в любом терминале)
```powershell
# Windows
py -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
copy .env.example .env   # затем впишите ключи
.venv\Scripts\python.exe main.py
```
Проверить настройки без запуска бота: `python main.py --check` — покажет, чего не хватает в `.env`, человеческим языком.

## 🔑 Настройка: два ключа

Все настройки — в файле `.env` (создается из `.env.example`).

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → токен вида `1234567890:AA...` |
| `DEEPSEEK_API_KEY` | [platform.deepseek.com](https://platform.deepseek.com/) → API Keys → пополнить баланс (несколько центов на месяц личного использования) |

**Про фото блюд (Vision):** разбор фотографий работает только с мультимодальной моделью. Ключ DeepSeek с моделью `deepseek-chat` — только текст; в `LLM_MODEL`/`LLM_BASE_URL` можно указать любой OpenAI-совместимый шлюз с Vision-моделью. Без Vision бот честно сообщит об этом при получении фото, все текстовые функции работают.

**Прочие ручки** (`LLM_TIMEOUT`, `WHISPER_MODEL`, `PROXY_URL`, `DB_PATH`) — с комментариями в `.env.example`.

## 🩺 Диагностика

| Симптом | Решение |
|---|---|
| «Не хватает настроек в файле .env» | Заполните `TELEGRAM_BOT_TOKEN` и `DEEPSEEK_API_KEY` (см. выше) |
| `ModuleNotFoundError` | Запускайте через `ЗАПУСК_БОТА.cmd` или поставьте `pip install -r requirements.txt` в `.venv` |
| Бот молчит после старта | Проверьте интернет/прокси (`PROXY_URL`), посмотрите лог в окне консоли |
| Фото: «модель не умеет анализировать изображения» | Нужна мультимодальная модель — см. «Про фото блюд» |
| Голос: долго первый раз | Модель Whisper (~75 МБ) скачивается однократно с HuggingFace |

Подробнее — ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md, раздел «Диагностика».
